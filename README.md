# Sales Data Analyzer

## Project Description
Sales Data Analyzer is a Python-based project that helps analyze sales data using Pandas and NumPy. It performs data cleaning, mathematical operations, statistical analysis, filtering, sorting, pivot table creation, and automatic data visualization.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Features
- Load sales data from a CSV file
- Explore and clean datasets
- Perform mathematical operations
- Combine and split data
- Search, sort, and filter records
- Perform aggregate functions
- Calculate statistical values
- Create pivot tables
- Perform NumPy array operations
- Generate automatic charts and graphs
- Save visualizations and analysis results

## Dataset
The project uses a CSV file containing:
- Date
- Product
- Sales
- Region
- Profit

## Installation

Install the required libraries:

```bash
py -m pip install pandas numpy matplotlib seaborn
```

## How to Run

1. Download or clone this project.
2. Keep the Python file and CSV dataset in the same folder.
3. Open the project in VS Code.
4. Run the following command:

```bash
py "project 9.py"
```

5. Select an operation from the terminal menu.

## Output
The project displays analysis results in the terminal and generates charts such as bar charts, pie charts, line graphs, scatter plots, histograms, and heatmaps.

Generated visualizations are saved in the `Visualizations` folder.
